# Dear Corner

Little Things, Lovely Spaces.

Online shop for aesthetic room decor, lamps and lighting, desk and stationery,
accessories and gifts in Bangladesh.

Stack: Vite + React 19 + TypeScript + Tailwind CSS v4 + React Router 7 + Supabase,
deployed on Vercel.

## Local development

Copy `.env.example` to `.env.local`, fill in your own Supabase URL and public
(anon) key, then run `npm install` and `npm run dev`.
